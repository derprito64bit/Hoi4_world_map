# TASK P08: Adjacencies — straits, canals, impassable borders, seam links, rules

## 1. OBJECTIVE
Produce `mod/map/adjacencies.csv` and `mod/map/adjacency_rules.txt` that give every historically crossable strait, every 1936 canal (Suez, Panama, Kiel, Corinth — others only with evidence), impassable borders across real barriers, and Pacific wrap-seam links, with localisation for each rule.

## 2. SCOPE & BOUNDARIES
- Active scope: `tools/make_adjacencies.py`, `data/adjacencies/*.csv` (hand-curated lists with sources), `mod/map/adjacencies.csv`, `mod/map/adjacency_rules.txt`, rule localisation file, `docs/logs/P08.md`, `docs/OPEN_QUESTIONS.md` (OPEN-1 status).
- FROZEN: provinces, states, regions, rasters.

## 3. CONTEXT
- Patterns, vanilla precedent list and seam problem: `.claude/skills/hoi4-map-modding/references/04-regions-adjacency-supply.md` §2; format `references/01-file-formats.md` (adjacencies + rules). Vanilla has 140 straits, 3 canals, 70 impassable.
- Seam geometry: `references/06-equal-earth.md` §4.

## 4. CONSTRAINTS
- Hard: header row first, terminator `-1;-1;;-1;-1;-1;-1;-1;-1` last.
- Hard: land–land straits `Through` a sea province; canals sea–sea `Through` a land province with a rule; impassable `Through -1`.
- Hard: each strait/canal row cites a source in the curated CSV (historical crossing, ferry, bridge, canal opening date ≤ start date).
- Hard: seam links are **experimental** until OPEN-1 is answered: put them in a clearly separated block at the end of the csv (before the terminator) with comment `SEAM`, generated by the script.
- Preference: straits only where the sea province between is ≤ ~40 km wide in reality.
- Discretion: arrow coordinates (-1 unless rendering needs them).

## 5. DECISION RULES
- If two land provinces already share a pixel edge → no strait row needed.
- If a mountain border has no historical military crossing → `impassable`, citing the barrier (e.g. glaciated main ridge) — use sparingly; vanilla uses 70.
- Seam links: for each pair of sea provinces facing each other across the cut within the same 1° latitude band → one link; test variant A (`sea` type, Through = one of the two sea provinces) is the default; record in OPEN-1 that the owner must test in game.

## 6. FAILURE MODES
1. Straits generated automatically everywhere two coasts are close (creates absurd crossings).
2. Canals that did not exist at the start date.
3. Rule names without localisation.
