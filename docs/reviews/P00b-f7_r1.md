## Do not fix (looks odd, is correct)
- **Region count fell from 444 to 435 and one-province regions from 14 to 5.** With connectivity required, fewer members can be dropped, so fewer leftover seeds start their own regions. README, loc and weatherpositions are regenerated consistently.
- **`regiongroup.neighbours` has no wrap contact, but the naval rule counts contact across the wrap.** The grouping is stricter than the engine, which is safe, and `Boxes.ok` already forbids regions that touch both edge columns.
- **`connected` is checked on all members, while the naval rule counts only `sea` members.** EXP-09's new sea regions contain only new SEA IDs, and the filler regions contain only LAKE IDs, so the two agree. The whole-map `naval_findings` guard in `Exp09.base` (vanilla regions plus new ones) is the authoritative check.
- **`grow_regions` still has `far[0]` as the fallback after filtering.** A connected region with 2 or more members always has at least 2 non-cut vertices (spanning-tree leaves), so `far` is never empty. The final `KitError` makes this failure loud instead of silent.
- **`naval.main` skips RETIRED but checks CONCLUDED.** This is intended: concluded builds must still reproduce their documented finding.
- **`build.py --build-root` is limited to `--check`.** Correct: building and `--validate` write, and must stay below `build/experiments`.
- **Region names such as "Bering Sea" in tests/registry.** These are identifiers matching the engine's log line, not committed game files.
