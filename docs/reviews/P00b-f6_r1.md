- Donor pixels come from provinces in other strategic regions (e.g. sea-70x440 takes from regions 44 and 51). Membership is unchanged, and the region-contiguity and guard checks cover the geometry.
- block-400 stays buildable with a "DO NOT RUN AGAIN" note: this keeps the rejected run reproducible.
