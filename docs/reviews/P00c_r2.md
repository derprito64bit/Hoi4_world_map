## Do not fix (looks odd, is correct)
- **`offglobe_mask` anchors on `float3 ApplyIce(` even in e, where nothing inside `ApplyIce` needs the helpers except noice.** Definitions must come before first use, and `ApplyIce` is the first function in the MainCode, so this is the only anchor that places the helpers before both call sites.
- **d compiles helpers that e also uses from the main shader.** Unused-in-part functions are fine in HLSL and GLSL. In d only `EE_OffGlobeWeight` is reached, from `ApplyIce`.
- **The inline fade uses `Input.pos.xz` while noice uses `vPos`.** Same value: vanilla passes `Input.pos.xz` as `vPos` (l.342).
- **`vals[key] >= OUTSIDE_FLOOR == 15.0`** is a Python chained comparison (`a >= b and b == 15.0`). It is intended, and pins the README's number.
- **The empty `HOI4_GAME_DIR` still finds the game.** `game_dir()` falls back to `settings.local.json` in a parent checkout, so the game tests run in the worktree. In a clean CI they skip, as documented in README l.48.
- **Invariants, determinism, data loss.** Not applicable: this WU produces no map data, RNG or geometry.
