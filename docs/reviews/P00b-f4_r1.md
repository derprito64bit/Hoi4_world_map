## Do not fix (looks odd, is correct)
- **Seam-patch region 309 cannot take the fallback under any box convention.** It has one member, so its mean is `x0 + w//2` of its own box: inside the box for w ≥ 2 under both the non-wrapping box (0..5631) and a seam-aware box (width 4). `h = 3` gives cy = y0 + 1, which is strictly inside.
- **Margin ≥ 1 also holds under the other box-width convention.** With span+2 instead of span+1, every member's centre moves by 0 or +1, so the truncated mean moves by 0 or +1, towards xmax/ymax. Those upper bounds are inclusive in the model, and the lower bound only moves further away. EXP-09 bars (6×20, 12×20) have even sides, so their centres are identical under both conventions.
- **KNOWN_RISK is narrow.**
  - It is consulted only for the guard-failure list, keyed on build ID + region ID + exact member-box signature.
  - The "moved centre path" check and the new-region "clear" check are separate and cannot be masked by it.
  - Vanilla region files cannot be overridden (`vanilla region … overridden`), a reused region ID raises in `layered_regions`, and vanilla provinces in new region files fail the "exactly once" rule. So the signature can only ever match vanilla's own 178 boxes.
  - Tests cover: stale signature, moved boxes, and a different region ID. `test_exp08_known_risk_signature_is_vanilla_region_178` pins it to vanilla.
- **The "no vanilla province changes its pixel set" rule really is enforced.** `vanilla_pixel_problems` checks that the vanilla block is array-equal to vanilla and that no padding pixel is `< n0`. In `pad_provinces`, `fix_x_crossings` can only move pixels between padding IDs. The game test flips one real padding pixel and checks that both messages fire and that the build is clean again after the restore.
- **`grow_regions`:** dropped members are always > the seed (every smaller ID is already assigned), so they seed later regions. All picks use `(dist, id)` or `sorted` keys, so set iteration does not leak into the output. The result is deterministic (a test re-runs it). The final loop guarantees every group passes `Boxes.ok`, or raises.
- **Removed test assertions:** "vanilla sea IDs used" and the `north_row - 16` bound in `test_changes.py` are superseded by the redesign: vanilla seas are now bars in their region's run, checked per run with widths. The new bound `>= north_row` is stricter. The padding test changed from "≤ 4 borrowed pixels" to "none", which is also stricter.
- **EXP-08-6144 has no seam patch:** the right padding separates the vanilla top row from the seam, so no four-province corner arises there.
- **Vanilla regions 289–304 have no weatherpositions line, and 189/253 have lines but no provinces:** same as vanilla.
- **Determinism elsewhere:** `new_colors` is seeded (`COLOR_SEED`). The weather-source choice ties break on `(-count, name)`, the region order on `sorted(groups)`, and units on `sorted(members)` / `sorted(rstates)`.
