## Do not fix
- **Region rect w = column span + 2 (302 for xmax − xmin = 300)** looks like an off-by-one, but the dump shows it. The same goes for y counted from the bottom.
- **13 vanilla regions with divisor 0** (147, 187, 188, 197, 2, 20, 207, 232, 237, 276, 302, 52, 62) have their mean inside a member box and load fine. Do not widen the guard to "divisor ≠ 0 always". That would be noisy (about 4 % of regions), and vanilla shows the fallback gate is real.
- **`trap_split` passes `frozen = everything except p`** and so drops the adjacency `frozen` set. That is fine, because `trap_candidates` has already filtered p against it.
- **24k-fix numbers the new pieces differently from 24k.** This is an experiment before P05, so the ID-stability rule does not apply. Pixel partitions differ only in the 4 parents that are declared.
- **The `target` in `build()` is now `len(root) − 1`** instead of `TARGETS[k]`. It gives the same value for 16k–30k, including the 20k build with smalls.
- **The guard freezes the parent with the fewest pieces, then the lowest ID.** It uses sorted iteration and is deterministic, and the 8-round cap raises instead of looping.
