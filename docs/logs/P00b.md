## 1. Interface contract P00c → P00b (EXP-09)
The two WUs run in parallel with disjoint scopes; EXP-09 needs both. Contract:
- P00c commits `assets/gfx/FX/experiments/EXP-09/variants.json`:
  `{"variants": [{"id": "a", "label": "...", "changes": "...", "defines": ["<repo-relative .lua>", ...], "shader_patches": ["<repo-relative .json>", ...]}]}`.
  Variant `a` = baseline (no defines, no shader patch) so the filler alone is visible.
- Define overrides: own `.lua` files under `assets/common/defines/experiments/EXP-09/`, assigning only the keys under test in the correct namespace (`NGraphics.CAMERA_OUTSIDE_MAP_DISTANCE_TOP/BOTTOM`, `NFrontend.CAMERA_MAX_HEIGHT`). They are installed into the test mod's `common/defines/` under a name that sorts after `00_*.lua`.
- Shader fade: **no vanilla shader text is committed.** P00c commits a patch spec `assets/gfx/FX/experiments/EXP-09/*.patch.json` = list of `{file, anchor, mode: before|after|replace, text}`; `anchor` is a unique string in the 1.19.3 vanilla file. P00b's build copies the vanilla shader from `$HOI4_GAME_DIR` into `build/` and applies the patch; the build fails loudly if an anchor is missing or not unique.
- P00b builds one mod per variant (`EXP-09a`, `EXP-09b`, …) from the manifest. If the manifest is absent (before P00c merges), it builds only the baseline and says so; its tests use a fixture manifest.
- After both merge, overwatch runs `build.py all --check` on main once more.
