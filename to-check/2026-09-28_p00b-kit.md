## How to run (every test)
1. `python tools/experiments/build.py all` once (≈2 min, 1.3 GB in `build/experiments/`, gitignored). Already done on this PC for `1b6c59a`.
2. Per build, follow `build/experiments/<ID>/README.txt`. Short version: `python tools/experiments/install.py <ID>` → launcher: new empty playset, tick only that mod → delete `logs/error.log` → play → send back what the README asks → `python tools/experiments/install.py <ID> --uninstall`.
3. Only one test mod may be ticked at a time. Copy `error.log` after every run, because the next one overwrites it.
